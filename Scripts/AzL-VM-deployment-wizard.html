Azure Verbindung
Verbinde dich mit Bearer Token. Ressourcen werden dann automatisch aus Azure geladen.
Schritt 1 — Azure CLI Login
Falls noch nicht angemeldet, zuerst in der Azure CLI einloggen:
az login --use-device-code
Schritt 2 — Bearer Token generieren
Anschliessend den Token abrufen und unten einfuegen:
az account get-access-token --resource https://management.azure.com/ --query accessToken -o tsv
